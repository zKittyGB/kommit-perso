# Raccourcis

Quand je tape un de ces raccourcis seul (ou en début de message), il correspond à la commande indiquée. Les exécuter directement, sans demander confirmation.

| Raccourci            | Commande                                 | Sens                                              |
| -------------------- | ---------------------------------------- | ------------------------------------------------- |
| `gp`                 | `git push`                               | Git Push                                          |
| `ga`                 | `git add`                                | Git Add                                           |
| `gc`                 | `git checkout`                           | Git Checkout                                      |
| `gm`                 | `git commit`                             | Git Commit                                        |
| `gm all` / `gmt`     | `git add -A && git commit`               | Git Commit de tous les fichiers modifiés/nouveaux |
| `gma`                | `git commit --amend --no-edit`           | Git Commit Amend (sans changer le message)        |
| `gme`                | `git merge`                              | Git Merge                                         |
| `pr pour` / `pr sur` | créer la PR pour / sur la cible indiquée | Ouvrir la Pull Request                            |
| `o` / `y`            | réponse « oui » / « yes »                | Oui                                               |
| `n`                  | réponse « non » / « no »                 | Non                                               |
